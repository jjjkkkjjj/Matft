# Generators of the expected values

The expected values of Matft's tests are computed by numpy / scipy / librosa / OpenCV / PIL / transformers, never by hand.
The scripts here write them as Swift literals or CSV files.

## Setup

Python 3.10 or later is required.

```sh
python3 -m venv .venv
.venv/bin/pip install -r python/requirements-test.txt
```

| `gen_reduce_coverage.py` | `Tests/MatftTests/ReduceCoverageTest.swift` | sum, squaresum, sumsqrt, mean, cumsum, ufuncReduce/ufuncAccumulate over axes, keepDims, dtypes, NaN/inf, empty axes and `layoutVariants` |
| `gen_manipulation_coverage.py` | `Tests/MatftTests/ManipulationCoverageTest.swift` | astype, reshape, transpose/swapaxes/moveaxis, expand_dims/squeeze, broadcast_to, flatten, flip, concatenate/stack, insert, take, sort/argsort, clip, roll, creation (arange, eye, diag, nums, ...), empty arrays and complex |

| `gen_empty_manipulation_coverage.py` | `Tests/MatftTests/EmptyManipulationCoverageTest.swift` | empty and zero-length arrays: astype, reshape/transpose/squeeze/broadcast_to, concatenate/stack/insert/take, pad/diff/meshgrid, getters and setters, linalg (0×0 and zero-length contractions), fft, pad_or_trim, interp |

| `gen_bughunt_stats_sort.py` | `Tests/MatftTests/BugHuntStatsSortTest.swift` | regressions from the 2026-09-27 bug hunt: sort/argsort with NaN over axes and layouts, cov ddof/rowvar, unique_all/counts/inverse NaN, stacked pinv |

The OpenCV reference images of the visual check (`Tests/MatftTests/files/images/opencv/*.png`) are written by
`scripts/image_compare.py` (see the `image-visual-check` skill).

## Regenerating

```sh
for g in python/gen_*.py; do .venv/bin/python "$g"; done
git status   # no diff with the pinned versions
```

The generated Swift files start with `// Generated by ... Do not edit by hand.` Edit the generator and run it again instead.
When you add a case, write the Swift expression and the Python expression computing its expected value in the same place,
and confirm the new test fails before the implementation (TDD).
