# Generators of the expected values

The expected values of Matft's tests are computed by numpy / scipy / librosa / OpenCV / PIL / transformers, never by hand.
The scripts here write them as Swift literals or CSV files.

## Setup

Python 3.10 or later is required.

```sh
python3 -m venv .venv
.venv/bin/pip install -r python/requirements-test.txt
```

## Generators

| Script | Writes | Covers |
|---|---|---|
| `gen_numpy_gaps_coverage.py` | `Tests/MatftTests/NumpyGapsCoverageTest.swift` | orderstats, nan-functions, argmax/argmin, var/std, searching, set operations, pad/diff/meshgrid, fit, interpolation, math, over dtypes and `layoutVariants` |
| `gen_fft_audio_coverage.py` | `Tests/MatftTests/FFTAudioCoverageTest.swift` | rfft/irfft (pocketFFT, vDSP), windows, stft, mel, power_to_db, pad_or_trim, whisper_log_mel |
| `gen_image_coverage.py` | `Tests/MatftTests/ImageCoverageTest.swift` | parameters of `Matft.image` against OpenCV / PIL, and the VLM preprocess |
| `gen_audio_fixtures.py` | `Tests/MatftTests/files/audio/*.csv` (+ printed literals) | the reference values of `AudioTest.swift` |
| `gen_image_preprocess_fixtures.py` | `Tests/MatftTests/files/image_preprocess/*.csv` (+ printed literals) | the reference values of `ImagePreprocessTest.swift` |

The OpenCV reference images of the visual check (`Tests/MatftTests/files/images/opencv/*.png`) are written by
`scripts/image_compare.py` (see the `image-visual-check` skill).

## Regenerating

```sh
for g in python/gen_*.py; do .venv/bin/python "$g"; done
git status   # no diff with the pinned versions
```

The generated Swift files start with `// Generated by ... Do not edit by hand.` Edit the generator and run it again instead.
When you add a case, write the Swift expression and the Python expression computing its expected value in the same place,
and confirm the new test fails before the implementation (TDD).
